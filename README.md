# Kyah Adams — Personal Research Website

A modern, responsive personal research website designed for PhD applications, conference visibility, and professional outreach.

## 1. Preview locally

Open `index.html` directly in your browser, or use a local server.

If you have Python installed:

```bash
python3 -m http.server
```

Then visit:

```text
http://localhost:8000
```

## 2. Personalize before publishing

Search `index.html` for the following placeholders and replace them:

- `YOUR_EMAIL_HERE`
- `YOUR_LINKEDIN_URL_HERE`
- `YOUR_GITHUB_URL_HERE`
- `YOUR_GOOGLE_SCHOLAR_URL_HERE`

Also add your current CV as:

```text
resume.pdf
```

in the root of the repository.

## 3. Publish with GitHub Pages

1. Create a new GitHub repository.
2. Name it `yourusername.github.io` if you want the cleanest URL.
3. Upload all files in this folder.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose the `main` branch and `/ (root)`.
7. Save.

Your website will appear at:

```text
https://yourusername.github.io
```

## Recommended next additions

For PhD applications, the strongest next upgrades are:

- Add a professional headshot or one strong research/environmental portrait.
- Add individual project pages with figures, methods, results, and your specific contribution.
- Add DOI / conference / poster / GitHub links for each research item.
- Add a downloadable academic CV.
- Add a “Research Statement” page.
- Add a short “Current Questions” section showing what you want to study in a PhD.
- Add Google Scholar and ORCID once populated.
- Add one or two visuals from MOCAT-MC / Catalyst research rather than generic space imagery.

## Design notes

The current visual direction uses:

- Warm ivory background
- Deep ink/navy
- Electric cobalt accent
- Editorial serif typography paired with a clean sans serif
- Generous whitespace
- Subtle motion
- No stock imagery required

This is intentional: it reads more like a strong academic / design portfolio than a generic resume website.
